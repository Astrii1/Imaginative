# Reference Corpus

This corpus provides visual and contextual references for `Imaginative.md`.

Don't try to acquire screenshots of all of them. For commercial sites, make the reference entry an annotated description + URL, and only include imagery you have a legitimate basis to redistribute. Your own/generated recreations can provide the visual examples.

### Learn

The website should feel like an extension of the physical business.

A barber shouldn't automatically become a SaaS company selling "next-generation grooming experiences."

A plumber might need:

> Phone → emergency service → areas covered → reviews → services

And it probably does not need elaborate 3D effects simply because the technology is available.
